## Description

Add Digital Ocean or Microsoft Azure as an alternative cloud provider to practice on, alongside AWS.

---

## Why This Matters

- Different cloud providers have different strengths and pricing models
- Digital Ocean is simpler and cheaper for small projects — great for learning
- Azure is dominant in enterprise environments and integrates deeply with Microsoft ecosystems
- Multi-cloud awareness is a key skill for modern engineers
- Learners should understand cloud portability and avoid vendor lock-in

---

## Learning Objectives

- [ ] Understand the differences between AWS, Azure, and Digital Ocean
- [ ] Set up a Digital Ocean account and use Droplets
- [ ] Set up an Azure account and use key services (VMs, AKS, Azure DevOps)
- [ ] Deploy the Notes App on Digital Ocean (optional)
- [ ] Deploy the Notes App on Azure (optional)
- [ ] Compare pricing, tooling, and developer experience
