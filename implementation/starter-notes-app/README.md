# Starter Notes App (Baseline)

This is the baseline app used to bootstrap the learner-first journey.

## Role in the New Pattern

- **Phase 1**: Frontend uses mock server (backend optional)
- **Phase 2**: Backend returns fixed/in-memory responses
- **Phase 3**: Backend persists to real database

After phase 3 is complete, this app becomes the base for infrastructure phases.
