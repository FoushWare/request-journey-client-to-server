# Capsule Projects

Capsule projects are independent projects used after core guided learning.

## Recommended Placement in Journey

- Primary use: **Phase 10 (other production capabilities)**
- Optional early use: after **Phase 7** to stress-test architecture decisions

## How to Use

1. Pick one project folder.
2. Start from `starter/`.
3. Implement requirements independently.
4. Use `hints/` progressively.
5. Compare against `final-solution/`.

## Available Projects

- e-commerce-app
- blog-platform
- todo-project-management
- realtime-chat
- api-gateway
